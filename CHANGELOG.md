# Changelog

## [1.0.0] — 2026-10-10
### Added
- Keyboard controls: `[` / `]` timing offset, `a` art toggle, `r` reload
- Disk cache at `~/.cache/lyrical/lyrics.json`
- Config file at `~/.config/lyrical/config.json`
- Smarter track matching (strips feat./remaster/version noise)
- `install.sh` / `uninstall.sh` for one-command desktop integration
- `assets/icon.svg` for app-menu icons

### Fixed
- Alt-screen buffer + absolute cursor positioning (no flicker, no scrollback growth)
